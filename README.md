# 🎬 Gestor de Películas - Macarena Aliberti

Este es mi segundo proyecto web: un **gestor de películas Full Stack** donde podés ver, agregar y gestionar información sobre películas. Fue realizado como parte de mi formación en desarrollo web.

---

## 🌐 Descripción

El proyecto está dividido en dos partes:

- **Frontend**: desarrollado con HTML, CSS, Bootstrap, JavaScript moderno y Webpack.
- **Backend**: construido con Node.js, Express y MongoDB para la persistencia de datos.

El objetivo es brindar una experiencia interactiva donde el usuario puede consultar películas y también agregar nuevas mediante un formulario.

---

## ✨ Funcionalidades

### 🖥️ Frontend
- Vista principal con tarjetas de películas.
- Modal para ver trailers (integrado con YouTube).
- Enlaces a:
  - Formulario de carga de nuevas películas.
  - Página sobre la historia del cine.
  - Sitios recomendados relacionados al cine.
  - Sección sobre mí.
- Uso de Bootstrap para diseño responsivo.

### ⚙️ Backend
- API REST desarrollada con Express.
- Conexión a base de datos MongoDB.
- Endpoints para:
  - Obtener todas las películas.
  - Agregar una nueva película.
  - Eliminar películas.

## 🚀 Cómo usarlo

### 1. Cloná el repositorio

```bash
git clone https://github.com/MacarenaAliberti-web/gestor-de-peliculas.git
```
```bash
cd gestor-de-peliculas/front
npm install
npm run build
npm start
```
Esto abrirá el proyecto en tu navegador con Live Server.

### 3. Backend (en otra terminal):
```bash
cd gestor-de-peliculas/back
npm install
npm start
```
Asegurate de tener MongoDB corriendo localmente (o ajustá la conexión si usás MongoDB Atlas).
